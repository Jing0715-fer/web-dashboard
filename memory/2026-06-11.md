# 2026-06-11 Web Dashboard 修复

## 修复的问题

### 1. 根目录 `app/` 目录导致 webpack 解析错误文件
- 根目录下有一个旧的 `app/` 目录（`page.tsx` 3109行 + `layout.tsx` + `globals.css`）
- webpack 优先解析了 `app/page.tsx`（旧版本）而不是 `src/app/page.tsx`
- 删除根目录 `app/` 目录后，Next.js 不再编译 `/` 路由
- 修复：删除根目录 `app/`，修复 `src/app/layout.tsx` 的 `next/font/local` 兼容性问题（改用 `@font-face`）

### 2. 项目列表为空
- `fetchProjects` 里 `data.map(...)` 应该是 `data.projects.map(...)`
- API 返回格式是 `{ projects: [...] }` 对象，前端直接当数组用了

### 3. Base UI PopoverTrigger warning
- 通知铃铛的 `PopoverTrigger` 传了 `<button>` 但 `nativeButton` 默认 `false`
- 修复：添加 `nativeButton` prop

### 4. `z-ai-web-dev-sdk` 模块缺失
- `analyze/route.ts` 顶层 import 了一个不存在的包
- 修复：改为 `require()` in try-catch
